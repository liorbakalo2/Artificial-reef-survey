# 08_paper/data - master dataset of the surf-reef review paper

Built 2026-10-15 by the dataset agent from the repo's audited sources (nothing outside 08_paper/data was changed; no web page was needed except the World Bank FX/CPI series).
Rebuild: `python3 -I 08_paper/data/src/build_reefs.py` (reads `src/reefs/<slug>.py`, `profiles_derived.json`, `profile_boscombe.json`, `fx_worldbank.json`).

## Files
| file | content |
|---|---|
| `reefs.json` | list of 13 objects (one per reef). Every field is a record `{value, unit, status, source[], location, note?, alternatives[]?}` (see "Record format"). `_references` maps each alias used to its full citation text. |
| `reefs_table.csv` | the same fields flat: for every field four columns `f`, `f__unit`, `f__status`, `f__src` (alias keys + location, <= 230 chars). Lists are joined with `; `. Full citations only in `reefs.json`. |
| `reefs_core.csv` | one NUMBER per cell for the analysis fields (plus `_status` columns): use this for plots/regressions. Text-valued cells (e.g. `1-2 (summer)`) are left empty here and kept in the other files. |
| `gaps.md` | what is unknown / assumed per reef (generated) plus the manual list of weak spots. |
| `profiles_derived.json`, `profile_boscombe.json` | transect metrics (crest, toe, ramp, gap, slope) extracted from the 3D model grids, with the profile arrays for the crest column. |
| `fx_worldbank.json` | annual FX (LCU per USD) and US CPI used for `cost_usd` (World Bank WDI, fetched 2026-10-15). |
| `src/` | scripts: `common.py` (helpers, citation lookup), `derive_profiles.py` (Borth, Cables, Narrowneck, Albany), `derive_others.py` (Palm Beach), `derive_boscombe.py`, `reefs/<slug>.py` (the data, one file per reef, with the reading location of every number), `build_reefs.py`, `gaps_manual.py`. |
`08_paper/data/profiles/` (if present) is NOT part of this dataset (another task).

## Record format
`value`: number, text, list or null. `unit`: unit and, where relevant, datum. `status`: **sourced** (a number or statement read in a cited source), **derived** (computed by us from sourced inputs or from a traced shape/3D model; the method is in `location`/`note`), **assumed** (an ASSUMPTION of this project or of the 3D agent, flagged), **unknown** (not found; `value` is null and `note` says what was checked). `source`: full citation strings (author, year, title, venue; pages/figures/tables are in `location`; DOI/URL where the repo holds one). Citations are copied from the repo's reference lists (METHODS_3D.md section 8, shape.json, cards); a citation that could not be found prints `not confirmed`. `location`: where it was read (page, table, figure, repo file/field). `alternatives`: other published/derived values for the same quantity, each with its own status, source and location. Repo files used as sources appear as `repo:` strings (e.g. `07_scale/shapes/<slug>/shape.json canonical.area_m2`); they were read, never edited.

## Conventions (important)
* **Depths are positive downward.** `crest_depth_msl_m` = depth of the SHALLOWEST crest point below mean sea level; a negative value means the crest is above MSL (Borth: -0.19 m; Boscombe's `crest_depth_lat_m` -0.56 m = dry at LAT). `crest_depth_lat_m` is below LAT (chart datum where the source says so). `seabed_depth_toe_m` and `seabed_depth_at_crest_m` are SEABED (bed) depths in m below MSL, not reef-surface depths.
* **Datums.** Each reef's 3D model uses z = 0 at MSL; conversions are in the `location` text: Narrowneck/Palm Beach `z_MSL = z_AHD - 0.12` (MSQ Gold Coast Seaway; the papers' rule would shift 0.24 m); Cables/Bunbury/Albany AHD is taken as MSL (Cables LWD = -0.716 m AHD; Albany LAT -0.74 m AHD); Mount Maunganui `z_MSL = z_CD - 1.13` (LINZ Tauranga, present MSL); Boscombe `z_MSL = z_ACD - 1.40` (survey zero ASSUMED chart datum); Borth `z_MSL = z_ODN - 0.31`; Prattes `z_MSL = z_MLLW - 0.849`. Opunake and Kovalam have no usable datum.
* **DEPTH GAP** (`depth_gap_m`) = `seabed_depth_toe_m` - `crest_depth_msl_m` (toe = bed at the seaward edge of the outline on the crest transect). **Ramp** (`seaward_ramp_length_m`) = horizontal toe-to-crest distance on the shore-normal transect through the shallowest crest cell (crest edge = seaward-most cell within 0.25 m of that column's maximum; sensitivity to 0.10/0.50 m in the note). **Slope** (`mean_seaward_slope`) = gap / ramp (m/m; 1:n in the note). For Narrowneck, Cables, Albany, Palm Beach, Borth they are DERIVED from the model.js grids (`derive_profiles.py`, `derive_others.py`); Boscombe from the idealised loft rule of METHODS_3D E10 on the model seabed (`derive_boscombe.py`; the 1:3 flank is an assumption); Mount Maunganui by hand from the METHODS rules plus the 2013 DEM (alternatives); Bunbury from the spherical-cap stand-in; **Prattes ramp and slope are ASSUMED (1:1 bag face)**; Opunake, Kovalam, Burkitts, Mexico: unknown. Borth uses the median over columns (long diagonal mound); the crest-transect value is in `alternatives`. Where a sourced crest depth exists the gap uses it (the model-crest value is in `alternatives`).
* **Distance offshore** (`distance_offshore_crest_m`) is measured from different shoreline definitions (MSL waterline of the image used, wet/dry-sand edge, back-of-beach defence line at Borth, pre-reef shoreline in the NSW review); the definition is in `unit`/`location`. Treat differences < 30 m as noise.
* **Tide ranges.** `tide_spring_range_m` = MHWS - MLWS (semidiurnal sites) from the cited planes; for mixed/diurnal sites (Prattes, Bunbury, Albany) it is the great diurnal range MHHW - MLLW (stated in `unit`). `tide_mean_range_m` = ((MHWS+MHWN) - (MLWS+MLWN))/2 (or MHW - MLW). The NSW review (Blacka et al. 2013 Table 4.3) lists "tide range" without a definition; those values are kept as alternatives.
* **Plan lengths.** Alongshore/cross-shore are the bounding box of the traced outline in the shore-aligned frame; the NSW review's maximum dimensions are alternatives. `footprint_area_m2` is the default outline of the 3D/shape work (page default), other outlines are alternatives. Several outlines are LOWER bounds or traces of the platform/design, see notes.
* **Cost.** `cost_local` = sourced amount in the stated currency (`currency`, `price_year`; price years marked ASSUMED in the note were not stated by the source). `cost_usd` = amount / World Bank annual-average official exchange rate of that year (nominal); `cost_usd_2024` = nominal USD x US CPI(2024)/CPI(year) (2025 uses the 2024 CPI). Both are DERIVED; they inherit the uncertainty of the price year. Values are for what each source calls the reef, which may include studies, or (Borth) the whole defence scheme.
* **Years.** `year_built` = construction start; `year_completed` = main phase (null if never completed).
* **Coordinates** are the same points as the page (04_build/data/reefs.json `location`): traced-outline centres (status derived), estimated centres (Bunbury: assumed), Prattes from the paper's survey window (+-150 m), Opunake = consent-area centre, Burkitts = platform centre, Mexico = undisclosed. `shape_on_page` = shown/hidden (footprint.display), `model_3d` = yes/no with default version and confidence.
* **Surf outcome vocabulary:** works / works rarely / does not work / mixed/disputed / unknown, with reasons and quotes in the note. This is a reading of the cited sources, not a measurement.

## Field dictionary
name, country, lat, lon, year_built, year_completed, purpose (surf / coastal protection / multi), material, volume_m3 (fill or rock, as stated; alternatives = other published/derived volumes), footprint_area_m2, plan_length_alongshore_m, plan_length_crossshore_m, reef_height_m (crest above the local bed), crest_depth_msl_m, crest_depth_lat_m, seabed_depth_toe_m, seabed_depth_at_crest_m, depth_gap_m, seaward_ramp_length_m, mean_seaward_slope, distance_offshore_crest_m, tide_spring_range_m, tide_mean_range_m, swell_hs_m / swell_tp_s / swell_dir (typical surfable swell as far as stated), design_wave, arm_angle_to_shoreline_deg (list = arms), arm_angle_to_swell_deg, surf_outcome, surfable_days_per_year, durability, sediment_shoreline_outcome, cost_local, cost_usd, cost_usd_2024, shape_on_page, model_3d; extra: reef_arm_note (Narrowneck).

## Cautions for the paper
* Only 5-6 reefs have a derived ramp/slope from audited geometry (Narrowneck, Cables, Albany, Palm Beach, Boscombe loft, Borth median). Do not fit relations through the whole set without the `_status` columns; Prattes (assumed), Mount Maunganui (assumed bed), Bunbury (stand-in) are weak.
* Typical swell (Hs, Tp, direction) is mostly UNKNOWN in the repo; the NSW review (Blacka et al. 2013 Table 4.3) gives Hs/T for Narrowneck 1.0 m, Mount Maunganui 1.5 m/11 s, Boscombe 0.5 m/4 s, Kovalam 1-2.5 m/11-15 s, Cables 1-2 (summer) and 1.5-2.5 m (winter) without definitions. Design waves of the original reports (Black & Mead 2001, Pattiaratchi 1999, Mead et al. 2010 full text) were not read for this dataset.
* The Haifa wave data in 01_source_notes (Shikmona buoy, SWH 0.45-0.98 m, Tp 5.7-7.7 s, 285-294 deg) are Lior's notes for the target site and are NOT part of this reef table.
* Gemini's numbers were not used.
