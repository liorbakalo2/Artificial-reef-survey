BATHYMETRY DATA TEXT FILES

The text files are in x,y,z format.
Co-ordinates use the GDA94 datum, projected to the relevant MGA UTM zone (e.g.Zone 50).
Z values are in metres relative to AHD where positive values are above AHD and negative values are below AHD.

The data has been collected using a variety of methods and over a long historical period. 
The accuracy of the data is therefore variable and DoT does not provide any warranty as to the accuracy of the Information nor as to its reliability.

Each file name includes a two character code that represents the area of the survey (see below) and a date that represents the end date of the survey capture (YYYYMMDD). The capture of the data may have occurred over several weeks, months or even years in some cases.  The filename also includes a suffix indicating the survey method as follows:
_Single = Singlebeam
_Levels = Terrestrial point elevations
_DigiSingle = Singlebeam data obtained from digitisation of hard copy maps
_Hand = Hand Lead - historical data captured using lead plumb lines

The majority of the surveys were originally captured using a local sounding datum, but they have all been converted to AHD datum.
However there are issues inherent in this conversion.  Please contact DoT (Tides@transport.wa.gov.au) for further advice on this if required.
