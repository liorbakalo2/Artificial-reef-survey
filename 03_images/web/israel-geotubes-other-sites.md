# Image index — Other Geotube / Sand-Container Installations, Israel coast

Note on this target: research (see the dossier) found that **no second geotube structure was actually built** anywhere on the Israeli coast besides Ashkelon (which has its own dossier/image set). The two candidate sites here — Tel Aviv/Hof HaTzuk and Netanya — both ended up built as **rock breakwaters** or **not built at all**; a third case ("armored geotube") never left the lab/pilot stage. So the images below show the real, documented *sites and events* (the 2019 Hof HaTzuk protest, the Netanya cliff itself), not a geotube structure, because none exists to photograph. All URLs curl-checked 200 + real image bytes (one server mislabels Content-Type but the downloaded file is a genuine JPEG, verified by viewing it).
