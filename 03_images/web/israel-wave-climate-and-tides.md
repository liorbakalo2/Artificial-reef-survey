# Image index — Israeli Mediterranean wave climate, surfable days and tidal range (israel-wave-climate-and-tides)

This item is a design-basis dataset (buoy/tide-gauge network + Lior's own field measurements), not a single built structure. There is no dedicated "official" photo of the Shikmona buoy itself in a usable license, and the researcher-supplied Isramar station pages (`shikmonaBuoyM.aspx`, `shikmonaTC.aspx`, `shikmona.aspx`, `tidehadera/default.aspx`) are live data-chart pages, not static licensed photographs — per project rules they are indexed only as reference pages in the dossier's "Image leads" section, not pulled in here as image entries. The images below instead document the physical site the buoy monitors: Bat Galim beach and Tel Shikmona, Haifa, immediately next to the IOLR marine-research campus that operates the buoy.
