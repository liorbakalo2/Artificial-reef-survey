# Footprint provenance — Xala Reef (mexico-reef-2026-unnamed)

Status: **verified**. Researched 2026-09-25; verified 2026-09-25 (see "Verification 2026-09-25" section at the end).

## Summary

No source located by this project (across the original card/dossier sweep of 2026-09-24, plus a fresh re-check of every source on 2026-09-25) discloses the plan-view shape, length, width, area, crest depth, or offshore distance of the Xala reef in Jalisco, Mexico. Our own verified card already recorded this as "Not disclosed — no length, width, crest depth, or fill volume found in any source found" [R1][R3][R4][R5], and this task's re-check confirms that finding rather than overturning it.

Because the deliverable format requires a polygon, this file supplies a clearly labeled **design-analogy placeholder**: a symmetric footprint envelope of 160 m (alongshore) × 80 m (cross-shore), area 11,200 m², crest depth 1.5 m below MSL, and 270 m offshore — all taken not from any Xala-specific source but from the one number set that is directly documented and directly comparable: Palm Beach Reef, Gold Coast, Australia, the only other reef publicly credited to the same designer, Simon Brandi Mortensen, using the same rock-mound (non-geotextile) construction method [R7]. Confidence: **low**. This record should be replaced the moment a real Xala design paper, permit drawing, or aerial photo becomes available.

Gemini's candidate values (~140 × 75 m, crest ~1.0–1.5 m, offshore ~180–250 m) sit close to — but consistently a bit smaller than — Palm Beach Reef's real figures, and Gemini cites no source that contains any of those numbers. The most likely explanation is that Gemini performed the same Mortensen/Palm-Beach analogy internally without disclosing it. See "Gemini comparison" below.

## Polygon construction

Coordinate convention: origin at the shoreline point nearest the reef's (unknown) centroid; x = alongshore (positive direction arbitrary — no source states a compass heading for Xala's shoreline or reef); y = offshore, positive seaward; shoreline approximated as y = 0.

Because no source gives Xala any asymmetry, arm angle, or apex direction, the polygon is a **symmetric, generic mound envelope** — not a chevron/V/delta — centered at (0, 270) with a half-length of 80 m alongshore and spanning y = 230 to y = 310 (80 m cross-shore), built as an octagon so the bounding box matches the 160 m × 80 m analogy figures exactly while looking like a plausible rounded rock-mound outline rather than a bare rectangle:

```
(-80,250) (-40,230) (40,230) (80,250) (80,290) (40,310) (-40,310) (-80,290) → close
```

Verified this task with Shapely 2.1.2: polygon is closed (first vertex == last), `is_valid` = True, `exterior.is_simple` = True (non-self-intersecting), computed area = 11,200.0 m² (matches the `area_m2` field exactly), and `max_dimension_m` = 164.9 m (greatest pairwise vertex distance).

**Net verdict**: Gemini's numbers are not verifiable against any of its own cited sources and were not confirmed by this task's independent re-check of the same sources. We do not certify Gemini's specific figures as correct or incorrect in an absolute sense (nobody has published Xala's true dimensions), but we can say with confidence that **Gemini's presentation as tilde-hedged-but-source-backed numbers is misleading** — no source it cites supports them, and the numbers' closeness to Palm Beach Reef's real, different, and unrelated dimensions is the most likely explanation for where they came from.
